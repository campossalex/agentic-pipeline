# AGENTS.md and Agent Skills

_Brief generated by the AAIF reference agent on 2026-10-26._

## TL;DR

- AGENTS.md is an open Markdown convention for repository-level instructions to coding agents, intended as a predictable “README for agents” and used by more than 60k open-source projects according to the site. [1]
- Agent Skills are a lightweight folder-based format for packaging reusable agent capabilities; each skill centers on a `SKILL.md` file with metadata and task instructions, and may include scripts, templates, and reference assets. [2]
- The two formats address complementary layers: AGENTS.md gives project-specific operating context such as setup, tests, style, and PR guidance, while Agent Skills package portable workflows and expertise that agents load on demand. [1][2]

## Findings

### AGENTS.md standardizes project instructions for coding agents

AGENTS.md is presented as a simple, open format for guiding coding agents in software repositories, with the site describing it as a dedicated and predictable place for context and instructions. [1] The page positions AGENTS.md as complementary to `README.md`: README files remain focused on human readers, while AGENTS.md can carry agent-oriented details such as build steps, tests, conventions, and other procedural guidance that might clutter human-facing documentation. [1] Suggested content includes project overview, build and test commands, code style guidelines, testing instructions, security considerations, commit or pull-request guidelines, deployment steps, and other information one would give to a new teammate. [1]

### AGENTS.md is intentionally flexible and hierarchical

The AGENTS.md site says there are no required fields because the file is standard Markdown, and teams can use whichever headings fit their repository. [1] For monorepos, the guidance is to add nested AGENTS.md files inside packages or subprojects, with the nearest file in the directory tree taking precedence for edited files. [1] The FAQ also states that explicit user chat prompts override AGENTS.md instructions, establishing a hierarchy where user intent is above repository documentation. [1]

### Agent Skills package reusable capabilities and procedures

Agent Skills are described as a lightweight, open format for extending agents with specialized knowledge and workflows. [2] A skill is a folder containing a `SKILL.md` file with at least `name` and `description` metadata plus instructions for performing a specific task; the folder can also bundle scripts, reference materials, templates, and other resources. [2] The site frames skills as a way to make domain expertise, repeatable workflows, and cross-product reuse available to agents in a version-controlled and portable form. [2]

### Agent Skills use progressive disclosure to manage context

The Agent Skills page describes a three-stage loading model: discovery, activation, and execution. [2] During discovery, agents load only each skill’s name and description; during activation, the agent reads the full `SKILL.md` when the task matches; during execution, the agent follows the instructions and may use bundled code or referenced files. [2] The stated benefit is that agents can have many skills available while only loading full instructions when the task calls for them. [2]

### Governance and ecosystem signals

The AGENTS.md page says the format emerged from collaboration across the AI software development ecosystem, names OpenAI Codex, Amp, Google Jules, Cursor, and Factory, and says AGENTS.md is stewarded by the Agentic AI Foundation under the Linux Foundation. [1] The Agent Skills page says the format was originally developed by Anthropic, released as an open standard, adopted by a growing number of agent products, and is open to ecosystem contributions via GitHub and Discord. [2]
